# Rules

Hard constraints for this project. Not suggestions.

## Commits
- **Never** add a `Co-Authored-By: Claude` trailer (or any Claude/AI attribution) to commits or PRs.

## UI / design
- **No icons or emojis.** No icon libraries, no emoji glyphs in UI copy, labels, or text.
- **No gradients.** Flat fills only — no `linear-gradient`, `radial-gradient`, or gradient utility classes.
